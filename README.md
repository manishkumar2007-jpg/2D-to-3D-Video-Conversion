PROJECT: 2D to 3D Real-Time Video Conversion

Requirements:
- Windows 10/11
- Python 3.x
- Internet connection for first model download
- Red/Cyan 3D glasses

Installation:
1. Create virtual environment
2. Install requirements
3. Run calibration
4. Save settings
5. Run player

Architecture:
2D Video
↓
Depth Estimation
↓
Depth Map
↓
Disparity
↓
Stereo Views
↓
Red/Cyan Anaglyph
↓
3D Glasses
